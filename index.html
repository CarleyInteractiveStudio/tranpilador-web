¿Qué es Carley Creative Code?

Es un modelo de lenguaje de última generación (Transformer) optimizado para generar, corregir y completar código de Creative Engine Scripting. Con solo ~125M de parámetros, consume menos de 1GB de RAM, lo que lo hace perfecto para su integración local en Windows.

Soporta nativamente la sintaxis híbrida en español de Creative Engine:

si (teclaPresionada("Space")) {
    fisica.applyImpulse(nuevo Vector2(0, -fuerzaSalto));
}

Entrenamiento Potente

Puedes entrenar el modelo con tus propias líneas de código usando nuestra infraestructura lista para Hugging Face y Google Colab. Soporta Fill-In-The-Middle (FIM) para correcciones de código en tiempo real.

Subir a Hugging Face Ver en GitHub

# Instala las dependencias
pip install torch transformers accelerate

# Inicia el entrenamiento
python training/start_training.py
